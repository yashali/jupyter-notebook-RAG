# Code Sage

Code Sage is a agentic AI system designed to streamline code generation and retrieval tasks. Leveraging Semantic Kernel, it configures the UserHelperAgent—to process user queries and respond appropriately. The system utilizes plugins for semantic searches and prompt-based code generation, ensuring accurate and context-aware responses. Ideal for developers seeking efficient code assistance. 

---

## ✨ Key Features

- **Multi-Agent Collaboration**: Seamless interaction between agent & plugins to handle complex tasks efficiently.
- **Semantic Memory Integration**: Utilizes Azure Cognitive Search for retrieving relevant information from stored data.
- **Dynamic Prompt Generation**: Constructs context-aware prompts for precise code generation.
- **Modular Architecture**: Easily extendable framework to incorporate additional functionalities or agents.
- **Real-Time Processing**: Delivers swift responses, enhancing user experience and productivity.
